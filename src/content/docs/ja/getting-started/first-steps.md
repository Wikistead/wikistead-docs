---
title: 最初の一歩
---

最初のページを作り、スペースに整理する。メンバーを招待し、共有リンクでゲストに渡す。この 4 つが Wikistead を使い始める流れです。通しで 5 分ほどで終わります。

## 1. ページを作る

ワークスペースを開き、サイドバーの**新規ページ**を押します。作成したページは、そのままエディタで開かれます。

編集画面は 1 つだけです。Markdown を打つと、打ったそばから描画されます。見出しやリスト、テーブル、コールアウト、図がその位置に現れますが、保存されている中身は素の Markdown のままです。プレビューを別ペインに開く必要はなく、書くモードと読むモードの切り替えもありません。Markdown の記号が見えるのはカーソルのある行だけで、他の行には描画結果が表示されます。

試してみてください。

```md
# チームハンドブック

ようこそ！ チームの知っていることはすべてここに。

- [ ] オンボーディングのチェックリストを足す
- [x] スペースの名前を決める

:::tip
コールアウトもテーブルも図もその場で描画されます。ページの下は Markdown のままです。
:::
```

## 2. スペースに整理する

ページは**スペース**に属します。チームやプロジェクト、トピックごとに 1 つ作るのが基本です。サイドバーには今いるスペースのページツリーが表示され、ページはドラッグで入れ子にできます。サイドバー上部のスペース切り替えから、他のスペースへの移動と新規作成ができます。

作りたてのページは**下書き**で、公開するまで自分にしか見えません。準備ができたら、ページの **⋯ メニュー**から**公開**を押してください。

## 3. リンクで共有する

ここが Wikistead のいちばん中心にある使い方です。ページの **⋯ メニュー → 共有** から共有リンクを作ります。そのリンクを開いた人は、**アカウントを作らずに**ページを読めます。リンクに与えた権限しだいで、コメントや編集もできます。ゲストが入ってくると、その人のカーソルと名前が画面に表示され、同時に書き込めます。

- 1 本のリンクが持つ権限は 1 つです（閲覧・コメント・編集）。
- リンクの失効は 1 回の操作で済み、そのリンクで入っていたゲストは、すぐにページを開けなくなります。
- ゲストはメンバーにはなりません。メンバー一覧にも載らず、課金対象の人数にも含まれません。

期限やスペース全体のリンク、失効の詳しい話は[共有リンク](/ja/guides/share-links/)にあります。

## 4. メンバーを招待する

継続的に参加してもらう人（名前とロールを持つ人）は、**管理 → メンバー**から招待します。メンバーはサインインしてワークスペースに入ります。メンバー一覧に表示され、招待時に割り当てたロールで権限が決まります。

この区別は意図的なものです。**メンバー**はチームの内側のための仕組みで、**共有リンク**はそれ以外の人のための仕組みです。Wikistead での共同作業はリンクから始まることが多く、必要になったときにメンバーになってもらう、という順番で使えます。
