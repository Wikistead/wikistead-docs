---
title: 最初の一歩
---

最初のページを作り、スペースに整理し、メンバーを招待し、共有リンクでゲストに渡す——Wikistead を使い始める 4 つの動きです。通しで 5 分あれば足ります。

## 1. ページを作る

ワークスペースを開き、サイドバーの**新規ページ**を押します。ページはそのままエディタで開きます。

編集面は 1 つだけです。Markdown を打つと、打ったそばからレンダリングされます——見出し・リスト・テーブル・コールアウト・図がその場に現れ、下にあるドキュメントは素の Markdown のまま。分割プレビューも、書く/読むのモード切替もありません。キャレットのある行だけが Markdown を見せ、それ以外は結果を見せます。

試してみてください：

```md
# チームハンドブック

ようこそ！ チームの知っていることはすべてここに。

- [ ] オンボーディングのチェックリストを足す
- [x] スペースの名前を決める

:::tip
コールアウトもテーブルも図もその場で描画されます——ページの下は Markdown のままです。
:::
```

## 2. スペースに整理する

ページは**スペース**に属します——チーム・プロジェクト・トピックごとに 1 つ。サイドバーには現在のスペースのページツリーが表示され、ドラッグで入れ子にできます。サイドバー上部のスペーススイッチャーでスペースを移動・新規作成できます。

作りたてのページは**下書き**で、公開するまで自分にしか見えません。準備ができたらページ操作の**公開**を押してください。

## 3. リンクで共有する

Wikistead の中心となる動きです。ページの **⋯ メニュー → 共有** から共有リンクを作ります。そのリンクを開いた人は、**アカウントを作らずに**閲覧——リンクに与えた能力によってはコメントや編集——ができます。ゲストはキャレットと名前ラベルを伴って現れ、あなたと同時にリアルタイムで書きます。

- リンクは 1 つの能力を持ちます：*閲覧*・*コメント*・*編集*。
- リンクの失効は 1 操作で、そのリンクから入ったすべてのゲストが即座に締め出されます。
- ゲストはメンバーになりません：メンバー一覧に載らず、シート数も消費しません。

期限・スペース全体リンク・失効の詳細は[共有リンク](/ja/guides/share-links/)へ。

## 4. メンバーを招待する

名前とロールを持ち、継続的にアクセスする**メンバー**にしたい人は、**管理 → メンバー**から招待を送ります。メンバーはサインインし、メンバー一覧に載り、割り当てたロールを持ちます。

この区別は意図的です：**メンバー**はあなたのチーム、**共有リンク**はそれ以外の全員のためのもの。Wikistead のコラボレーションの多くはリンクから始まり、必要になったときだけメンバーシップになります。
