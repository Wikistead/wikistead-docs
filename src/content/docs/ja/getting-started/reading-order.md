splash のカードもサイドバーも、全ページを並べているだけで、どれから読むべきかは示していません。ここに並べるのは網羅ではなく、6 枚ほどの読む順です。

1. [はじめの一歩](/ja/getting-started/first-steps/)：ページを作り、スペースに整理し、共有し、チームメイトを招待する。
2. [Markdown 記法](/ja/reference/markdown-notation/)：この先のページが「書ける前提」で使う記法の早見表。
3. [ページ](/ja/guides/pages/)：下書き、公開、リンク、版の履歴。
4. [スペース](/ja/guides/spaces/)：木の分け方。
5. [共有リンク](/ja/guides/share-links/)：有効期限、範囲、失効。
6. [エディタのマクロ](/ja/editor/callouts/)：素の Markdown だけでは足りなくなったら。
