---
title: テーブル
---

Wikistead のテーブルには 2 つの形があり、その間の移動は自動です：単純な用途には標準の **GFM パイプテーブル**、セル結合やパイプテーブルで表現できない配置が必要になった瞬間に **`:::table` マクロ**（HTML 本文のテーブル）へ。

## パイプテーブル（既定）

```md
| 領域          | 担当 | 状態 |
| ------------- | ---- | ---- |
| アナウンス     | Mia  | 完了 |
| デモ          | Rin  | 下書き |
```

パイプテーブルはその場で実際の表として描画され、マウスで編集できます：セルをクリックして入力し、表のコントロールで行・列を追加・削除します。編集は操作ごとにコミットされるので、共同編集者には変更が起きたそばから見えます。

## リッチテーブル——`:::table`

セルを結合したり既定以外の配置を設定したりすると、テーブルは自動的に `:::table` 形に**昇格**します。本文は素の HTML テーブルです：

```md
:::table
<table>
  <thead>
    <tr><th>四半期</th><th colspan="2">目標</th></tr>
  </thead>
  <tbody>
    <tr><td>Q1</td><td>エディタを出す</td><td>ドキュメントを出す</td></tr>
  </tbody>
</table>
:::
```

`rowspan` / `colspan` と配置はここで保持されます。マウス編集も同じように使えます——HTML を手で触る必要はほとんどありませんが、読める形でいつでもそこにあります。

## Open formats：降格も自動

昇格は双方向に働きます。後で結合と配置を外せば、テーブルは**素のパイプテーブルに降格**されます——ドキュメントは常に、それを表現できる最も標準的な Markdown の水準に置かれます。リッチ形に閉じ込められることはありません。

## 補足

- セルの中身は改行つきテキストです。レンダラはセルをテキストノードから組み立て、生の HTML を注入しません——セルに悪意あるマークアップを貼ってもページでスクリプトは動きません。
- エクスポートはテーブルを保持します：パイプテーブルは GFM のまま、`:::table` は HTML 本文ごと出力されます。
