---
title: レイアウトマクロ
---

Markdown を「増やす」のではなく「並べる」コンテナディレクティブが 3 つあります：**columns**・**tabs**・**details**。それぞれの本文は普通の Markdown で、エディタが他で描画できるものはこの中でも描画されます。

## カラム

```md
:::columns
:::column
左側——リスト・テーブル・画像。
:::
:::column
右側。
:::
:::
```

広い画面では項目が横に並びます。編集中もコンテナは安定した枠のままです：カラムをクリックすると中身をその場で編集でき、項目ごとのコントロールでカラムを追加・削除できます。

## タブ

```md
:::tabs
:::tab[macOS]
macOS の手順。
:::
:::tab[Windows]
Windows の手順。
:::
:::
```

各 `:::tab[ラベル]` が 1 つのタブになり、読者が切り替えます。プラットフォーム別の手順や、一度に 1 つの変種だけ見たい before/after 比較に向いています。

## 折りたたみ（details）

```md
:::details[移行が触るもの]
既定では畳まれている長い答え。
:::
```

ラベルを要約行とする折りたたみセクションです——本文に入れるには長すぎる補足の定位置。

## 編集モデル

コンテナは**その場で**編集します：スロットをクリックするとそのスロットの Markdown のインラインエディタが開き、作業中も枠は崩れません。生の `:::` 形は Source モードでいつでも見られ、エクスポートが運ぶのもこの形です——Wikistead を持たない読者にも、各項目の中身が順番に見えます。
