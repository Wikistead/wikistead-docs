title: タスク
---

タスクリストは標準 GFM です——そしてチェックボックスは**インタラクティブ**：編集権限のある読者がボックスをクリックすると、下の Markdown が `- [ ]` と `- [x]` の間で切り替わり、全共同編集者にリアルタイムで反映されます。

```md
- [x] アナウンスを書く
- [x] デモをリハーサルする
- [ ] スクリーンショットを撮る
- [ ] 出荷する
```

## 進捗リング——`:::todo`

タスクリストを `:::todo` で包むと、**進捗リング**（完了 / 総数）付きの色付きパネルに昇格します。ラベルも付けられます：

```md
:::todo[ローンチのチェックリスト]
- [x] アナウンスを書く
- [ ] 出荷する
:::
```

本文は本物の GFM タスクリストのままです——同じインタラクティブなチェックボックスに、件数が付きます。ページヘッダにもページ全体の完了/総数チップが表示されるので、チェックリストのページは一目で自分の状態を語ります。

## タスクトラッカーではなく、知識のために

Wikistead のタスクは意図的に「ただの Markdown」です：担当者も期限もボードもありません。これは知識の*中に*住むチェックリスト——ランブック・ローンチページ・議事録——のためのもので、素の GFM だからこそどこへでもエクスポートでき、どのツールでも同じ意味を持ちます。本格的なプロジェクト管理は、ページをトラッカー化するのではなく[トラッカーと組み合わせて](/ja/editor/embeds/)ください。
