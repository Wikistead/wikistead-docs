---
title: コールアウト
---

コールアウト（admonition）は、読者に見逃してほしくない一文を、アイコン付きの色付きパネルで囲みます。5 つの型があり、それぞれが独立したディレクティブです：

```md
:::note
中立的な補足。
:::

:::info
読者が知りたいかもしれない背景。
:::

:::tip
知っておくと得する近道。
:::

:::warning
うまくいかない可能性のあること。
:::

:::danger
破壊的・不可逆なこと。
:::
```

## ラベル

どのコールアウトにも、開始行の角括弧で見出しを付けられます：

```md
:::warning[移行の前に]
先にバックアップをエクスポートしてください——移行はすべてのページ id を書き換えます。
:::
```

## 本文は Markdown のまま

コールアウトの中身は普通の Markdown です——リスト・リンク・コードフェンス・他のマクロもその中で描画されます。エディタではパネルがその場に描画され、キャレットを中に置くと `:::` フェンスが現れて、いつでも生の形を編集できます。

## 補足

- 型は大文字小文字を区別しません（`:::WARNING` は `:::warning`）。
- 未知の型（`:::something`）は壊れずに `note` として描画されます——Obsidian と同じ慣習です。
- エクスポートされる Markdown は `:::` ディレクティブをそのまま保持します。広く理解されるコンテナ記法で、中身はいずれにせよ標準 Markdown です。
