---
title: 埋め込みとトランスクルージョン
---

外部のコンテンツをページに持ち込むディレクティブは 2 つ：`:::embed-page` は**別の Wikistead ページ**を、`:::embed-external` は**許可リスト済みの外部 URL** を埋め込みます。どちらもマクロパレットからピッカーで挿入します——生の記法は可搬性のためにあり、手打ちのためではありません。

## ページの埋め込み（トランスクルージョン）

```md
:::embed-page
<pageId>
:::
```

対象ページの内容が現在のページの中に描画され、ライブに保たれます——元ページを編集すれば、すべての埋め込みが追従します。重要な性質が 2 つ：

- **読者ごとの権限チェック。** 埋め込みはアクセスを広げません：対象ページを閲覧できない読者には、埋め込み位置に何も見えません。埋め込み元のページが見えていてもです。
- **正典はソース。** ドキュメントには参照だけが保存され、エクスポートでは埋め込みはコピーの凍結でなくリンクに degrade します。

パレットの**ページを埋め込む**から挿入し、対象を選びます——<kbd>Ctrl</kbd>+<kbd>Enter</kbd> でいつでも差し替えられます。

## 外部 URL の埋め込み

```md
:::embed-external
https://example.com/dashboard
:::
```

外部埋め込みは**サンドボックス化された iframe** として描画され、管理者が許可リストに載せたホスト（**管理 → 埋め込み**）だけが対象です。リストにないホストの URL は素のリンクに degrade します——壊れたフレームにも、訪問者を追跡できる任意の iframe にもなりません。

これは意図的な信頼境界です：埋め込みは Wikistead をダッシュボード・動画・デザインツールと組み合わせる手段で、許可リストは「どの第三者をページの中で動かすか」を管理者が決める手段です。

## エクスポート時の挙動

どちらの埋め込みも Markdown/HTML エクスポートでは**リンクに degrade** します——別の場所に住むコンテンツの誠実な表現です（Open formats：エクスポートに壊れたフレームや特権付きフレームは含まれません）。
