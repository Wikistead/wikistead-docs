タグはページの **frontmatter** に書きます。ドキュメントの先頭に置く標準的な YAML のブロックで、多くの静的サイトジェネレーターが読み取れる形式です。

```md
---
tags: [decision, infra]
---

# Postgres を選んだ理由
```

![そのタグが付いたページを集めた `:::tagged` の一覧が表示されているところです。](../../../../assets/screenshots/tags.png)


エディタでは、frontmatter の内容がページ上部にタグの一覧として表示されます。ページ上でタグを追加したり削除したりでき、すでにあるタグから候補も出ます。生の YAML を直接編集したいときは、カーソルをブロックの中に置いてください。自分で足した他の frontmatter の項目はそのまま残ります。Wikistead が扱うのはタグだけで、他のメタデータには触れません。

## タグでページを一覧する

`:::tagged` を使うと、指定したタグが付いたページの一覧を自動で表示できます。本文の最初の行にタグ名を書きます。

```md
:::tagged
decision
:::
```

- タグの一致では大文字と小文字を区別しません。タグはただの文字列なので、同じ frontmatter を他の Markdown ツールで開いても同じ意味で読めます。
- 一覧は**読む人の権限で絞り込まれます**。閲覧できないページは、一覧からも件数からも外れます。
- [`:::children`](/ja/editor/page-lists/) と同じで、一覧は表示のためのものです。ドキュメントに保存されるのは、どのタグを一覧するかという指定だけです。

## frontmatter を使う理由

Markdown を扱うツールのあいだで唯一共通している、メタデータの書き方だからです。Wikistead のページをエクスポートすればタグも一緒に付いていき、Hugo や Jekyll、Obsidian、ふつうのテキストエディタでも読めます。タグが別のデータベースの中だけに残って、ページと切り離されることがありません。
