title: タグ
---

タグはページの**フロントマター**——ドキュメント先頭の標準 YAML ブロック、静的サイトジェネレータが皆読むあの慣習——に置きます：

```md
---
tags: [decision, infra]
---

# Postgres を選んだ理由
```

エディタではフロントマターがページ上部のタグチップの列として描画されます。チップ上で直接タグを追加・削除でき（既存タグからのサジェスト付き）、キャレットをブロック内に置けばいつでも生の YAML を編集できます。手で足した他のフロントマターのフィールドはそのまま保持されます——Wikistead はタグを表示し、それ以外のメタデータには触れません。

## タグでページを一覧する

`:::tagged` は、指定したタグを持つページの自動更新リストを描画します。本文の最初の行がタグ名です：

```md
:::tagged
decision
:::
```

- タグの一致は大文字小文字を区別しません。タグは素の文字列なので、同じフロントマターはどの Markdown ツールでも同じ意味を持ちます。
- リストは**読者ごとに権限フィルタ**されます：読者が閲覧できないページはリストからも件数からも消えます。
- [`:::children`](/ja/editor/page-lists/) と同じく、リストは表示出力です——ドキュメントに保存されるのはクエリだけです。

## なぜフロントマターか

Markdown の世界がすでに合意している唯一のメタデータ慣習だからです。Wikistead のページをエクスポートすればタグも一緒に運ばれ、Hugo・Jekyll・Obsidian・テキストエディタで読めます——失くしうるサイドカー DB はありません。
