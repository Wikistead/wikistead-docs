エディタのツールバーにある **Vim** ボタン、または <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>V</kbd>(設定 → アカウント → エディタで再割り当て可能)で切り替えます。効くのは編集中だけで、閲覧中は何も起きません。

**タッチデバイスと WYSIWYG モードでは Vim は使えません。** ボタンは表示されたまま無効になり、どちらの理由かはツールチップに出ます。Live や Source に切り替える、またはキーボードとマウスに戻せば自動的に使えるようになります。設定自体はどちらの状態でも保持されます。

## 起動時の状態

設定 → アカウント → エディタ → **キーマップ**:

- **この端末の最後の選択に従う**
- **毎回 Vim で起動**
- **毎回オフで起動**

## 保存と終了

`:w` は公開してエディタに留まります。`:wq` は公開してページ表示に戻ります。`:q` は公開せずにエディタを閉じます。

## システムクリップボード

設定 → アカウント → エディタ → **vim とシステムクリップボード**:

- **オフ**(既定)：ヤンクと削除は vim 自身のレジスタに留まります。`"+y` と `"+p` がシステムクリップボードへの橋渡しです。
- **貼り付け**：無印の `p` / `P` がエディタの外でコピーしたものを貼り付けます(裸の URL は Ctrl+V と同じくリンクになります)。カウントや名前付きレジスタなど、それ以外は普段どおりの vim の動きです。

## 同じタブの他の設定

- **vim のときは等幅**：既定で ON。フォントを見るだけでどちらのモードか分かります。
- **Vim** ボタン自体は自分のアカウントで非表示にできます。非表示にしてもショートカットは効いたままです。

## 補足

- テーブルのセルなど、マクロの編集面の中では <kbd>Esc</kbd> はまず vim の挿入モードを抜け、次にその面自体を抜けます。
- 表・図・図形は vim のモーションの下で 1 つのまとまりとして動き・消えます。編集中に戸惑ったら[うまく動かないとき](/ja/guides/troubleshooting/)へ。
