---
title: Vim モード
---

Wikistead は本物の Vim モードを積んでいます——CodeMirror の Vim エンジンによるモーダル編集で、キーバインドの上塗りではありません。エディタ下部バーの **Vim** スイッチで切り替えます。設定はアカウントごとで、セッション中に切り替えてもライブドキュメントから切断されません——共同編集もプレゼンスもトグルをまたいで動き続けます。

## 使えるもの

ノーマル / インサート / ビジュアルモード、モーション、オペレータ、カウント、レジスタ、検索——下のエンジンが備える Vim の語彙が、打ったそばから描画されるドキュメントに適用されます。

## マクロの中の Vim

面白いのは Vim と描画済みブロックの出会い方です。テーブル・図・ドローイング・レイアウトコンテナは Vim にとって**アトム**です：

- `j` / `k` は描画済みブロックを **1 つ**のモーションストップとして越えます——50 行の図は 50 歩でなく 1 歩。
- キャレットが描画済みウィジェットの*中に*勝手に落ちることはありません。ブロックは全体として選択されます。
- ブロック上の `dd` はブロック全体——フェンスも本文も——を削除します。
- 中を編集するには <kbd>Ctrl</kbd>+<kbd>Enter</kbd>——意図的な「ブロックに入る」操作です。

画面で 1 つに見えるものは、`d`・`y`・移動でも 1 つとして振る舞う——このメンタルモデルの誠実さを保っています。

## システムクリップボード

初期状態の Vim モードはレジスタが純粋です。エディタの外でコピーしたものと中でヤンクしたものは分かれたままで、`"+y` / `"+p` が明示的な橋渡しになります。Vim に慣れた手が期待するとおりの挙動です。

エディタの外でコピーしたものを素の `p` / `P` で貼り付けたい場合は、**設定 → アカウント → エディタ → vim とシステムクリップボード**を**貼り付け**に切り替えてください。このモードでは URL の貼り付けが <kbd>Ctrl</kbd>+<kbd>V</kbd> と同じように自動でリンクになります。カウント（`3p`）や名前付きレジスタ（`"ap`）など、それ以外の操作は Vim 本来の挙動のままです。どちらのモードでも、ヤンクや削除がシステムクリップボードに書き込むことはありません。

## 補足

- Vim モードはユーザーごとです：チームメイトには同じページが見え、それぞれが自分の編集スタイルを持ちます。
- マクロの編集面（テーブルのセル・レイアウトのスロット）の中では、<kbd>Esc</kbd> はまず Vim のインサートモードを抜け、次に面を出ます——各層で Vim の手が期待するとおりに働きます。
