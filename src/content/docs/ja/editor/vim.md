---
title: Vim モード
---

Wikistead の Vim モードは、キーバインドを似せたものではありません。CodeMirror の Vim エンジンによる本格的なモーダル編集です。エディタ下部のバーにある **Vim** スイッチで切り替えます。設定はアカウントごとに保存され、編集の途中で切り替えても、共同編集の接続は切れません。他の人のカーソル表示も、切り替えの前後で止まりません。

## 使えるもの

使えるのは、ノーマル / インサート / ビジュアルの各モード、モーション、オペレータ、カウント、レジスタ、検索です。Vim エンジンが対応している操作は、ライブプレビューのページ上でもそのまま使えます。

## 描画されたブロックと Vim

Vim と描画済みブロックの関係には、特別な決まりがあります。テーブルや図、ドローイング、レイアウトマクロは、Vim から見ると 1 つのかたまりとして扱われます。

- `j` / `k` は描画済みブロックを **1 回の移動**で越えます。50 行の図でも 1 回で越えます。
- カーソルが描画済みのウィジェットの中に勝手に入ることはありません。ブロックは全体が選択されます。
- ブロックの上で `dd` を押すと、フェンスも本文も含めてブロック全体が消えます。
- 中を編集したいときは <kbd>Ctrl</kbd>+<kbd>Enter</kbd> を押します。「ブロックに入る」ための操作です。

画面で 1 つに見えるものは、削除（`d`）でもヤンク（`y`）でもカーソル移動でも、1 つとして扱われます。

## システムクリップボード

初期状態では、Vim のレジスタとシステムのクリップボードは分かれています。エディタの外でコピーしたものと、中でヤンクしたものは混ざりません。両者をやり取りするときは `"+y` と `"+p` を使います。Vim に慣れた人が期待するとおりの動きです。

エディタの外でコピーしたものを素の `p` / `P` で貼り付けたい場合は、**設定 → アカウント → エディタ → vim とシステムクリップボード**を**貼り付け**に切り替えてください。このモードでは、URL を貼り付けると <kbd>Ctrl</kbd>+<kbd>V</kbd> と同じように自動でリンクになります。カウント（`3p`）や名前付きレジスタ（`"ap`）など、それ以外の操作は Vim 本来のままです。どちらのモードでも、ヤンクや削除がシステムのクリップボードに書き込むことはありません。

## 補足

- Vim モードはユーザーごとの設定です。同じページを開いている他のメンバーは、それぞれ自分の編集スタイルで書けます。
- マクロの編集画面（テーブルのセルやレイアウトの各枠）の中では、<kbd>Esc</kbd> はまず Vim のインサートモードを抜け、もう一度押すとその画面から出ます。
