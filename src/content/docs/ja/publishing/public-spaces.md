---
title: 公開スペースと公開ページ
---

書くことと公開することは、別々に決められます。同じページを、非公開のままにしておくことも、チームに公開することも、Web に公開することもできます。公開は設定を変えるだけで、ページを別の場所に移す必要はありません。

## 3 種類の読者

| 読者 | 入り方 |
|---|---|
| **メンバー** | サインインして、自分にアクセス権のあるページを読みます。 |
| **ゲスト** | [共有リンク](/ja/guides/share-links/)から入ります。権限は限定でき、いつでも失効できます。 |
| **匿名の読者** | 公開されたページとスペースを読みます。URL さえ知っていれば、リンクをたどらなくても開けます。 |

## 公開する

公開機能は、既定では無効です。ワークスペースの管理者が**管理 → 公開設定**で有効にすると、次の 2 つができるようになります。

- **ページを公開する**：そのページが公開 URL で読めるようになります。見えるのは最後に公開した版です。
- **スペースを公開する**：スペースの公開済みページが、ツリー付きの読み取り専用サイトとして公開されます。

公開されるページには、常に 2 つの決まりがあります。

- **公開した内容だけが表示されます。** 下書きと未公開の編集は、他の設定がどうであっても公開側には出ません。
- **読み取り専用です。** 匿名の読者が読めるのは公開されたページだけで、公開していないページは、存在しないものとして扱われます。

ページの一覧やタグ一覧のように、内容が変わるマクロは、匿名の読者にはページを公開した時点の内容で表示されます。公開ページが、閲覧のたびにワークスペースへ問い合わせを行うことはありません。

## 独自ドメイン

ワークスペースの公開ページは、独自のドメイン（docs.your-company.com など）から配信できます。ドメインの追加と所有確認は、ワークスペースの設定で行います（利用できるかどうかはデプロイの構成とプランによります。[プラン別の機能一覧](/ja/reference/plan-contents/)を参照してください）。

## すべてを持ち出す

Web への公開は、外に出す方法の 1 つです。もう 1 つはエクスポートで、こちらに機能上の制限はありません。

- **ページ**：Markdown（`.md`。子ページや添付があるときは画像を同梱した `.zip`）。
- **ページを HTML で**：公開版の内容を、スクリプトを含まない 1 ファイル完結の HTML にしたものです。
- **スペース**：閲覧できるページをまとめて 1 つの Markdown ZIP に書き出します。スペースのページタブからは、選んだページだけの書き出しもできます。
- **ワークスペース**：ワークスペース全体を 1 つの Markdown ZIP に書き出します。どのプランでも使えます。

エクスポートの中身は、実行した人のアクセス権で絞り込まれます。自分が読めるページはすべて書き出せますが、それ以外は含まれません。
