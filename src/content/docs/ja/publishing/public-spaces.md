---
title: 公開スペースと公開ページ
---

「書き方」と「公開方法」は別の判断です。同じページを、非公開のまま・チームに開いて・Web に公開して出せます——公開は設定であって、引っ越しではありません。

## 3 つの読者

| 読者 | 入り方 |
|---|---|
| **メンバー** | サインインし、アクセス権の範囲を見る。 |
| **ゲスト** | [共有リンク](/ja/guides/share-links/)——能力スコープ付き・失効可能。 |
| **匿名の Web** | *公開*されたページとスペース。URL さえあれば誰でも読める——リンクすら不要。 |

## 公開する

公開露出は、ワークスペース管理者が有効化（**管理 → 公開**）するまでオフです。有効化すると：

- **ページを公開する** — そのページは公開 URL で、最後に*公開*された版として読めるようになります。
- **公開スペース** — スペースの公開済みページが、専用のツリーナビゲーション付きの読み取り専用サイトとして現れます。

公開面の全域で 2 つの不変条件が成り立ちます：

- **公開済みコンテンツのみ。** 下書きと未公開の編集は、他に何が設定されていても公開面には決して見えません。
- **読み取り専用・存在秘匿。** 匿名の読者は公開されたものだけを読めます。それ以外は存在しないかのように応答します。

動的ブロック（ページリスト・タグリスト）は、匿名読者にはページ公開時に焼き込まれたスナップショットとして描画されます——公開面があなたのワークスペースにライブで問い合わせることはありません。

## 独自ドメイン

ワークスペースの公開面は独自ドメイン（docs.your-company.com）から配信できます——ワークスペースの設定で追加・検証します。デプロイとプランが許す場合です（[entitlement レバー](/ja/reference/generated/entitlement-levers/)参照）。

## すべてを持ち出す

Web への公開は出口の 1 つで、コンテンツを持って出るのはもう 1 つの出口です。こちらは決して制限されません：

- **ページ** → Markdown（`.md`。サブツリーや添付があるときは画像同梱の `.zip`）。
- **ページを HTML で** — 公開版の、自己完結・サニタイズ済み HTML ファイル。
- **スペース** → 閲覧できるすべてを 1 つの Markdown ZIP で。スペースのページタブからは選択エクスポートも。
- **ワークスペース** → 全体を 1 つの Markdown ZIP で。全プランで使えます。

エクスポートは呼び出し元ごとに view でフィルタされます——読めるものを持ち出せる、それ以上ではありません。
