他の wiki のエクスポートをアップロードすると、その中身がスペースのページとして再現されます。形式は**アーカイブ自体から判別**するので、古いツールが出したファイルをそのまま渡してください。

| 取り込み元 | アップロードするもの |
|---|---|
| **Obsidian** | vault フォルダを zip にしたもの |
| **Notion** | 公式の Markdown & CSV エクスポート |
| **Confluence** | HTML エクスポート |
| **Docmost** | ページまたはスペースの Markdown エクスポート |
| **Wikistead** | この製品が書き出した zip（ワークスペース間の移動に使います） |

## 取り込みの手順

スペースを開き、**スペース設定 → インポート**に進みます。アーカイブを選んで開始します。終わると同じ画面にレポートが出ます。

取り込んだページは**入った時点で公開されます**。先に自分で目を通してから見せたい場合は、開始する前に公開のスイッチをオフにしてください。すべて下書きとして入ります。大きなアーカイブはその場では終わらず、サーバ側の仕事になります（詳しくは後述）。

## 何が入り、何が入らないか

**ページは公開された状態で入ります。** 取り込みが終わった時点で読めます。公開スペースなら、ワークスペースの外からも読めるようになります。これは開始する前に画面が伝えます。

**公開のスイッチをオフにした場合**は、すべて下書きとして入ります。このスペースを編集できる人にしか見えず、公開するまで閲覧面にもエクスポートにも出ません。

最後に出るレポートには、**入らなかったものが名前で**並びます。

- **取り込んだページどうしのリンクは書き換えられます**。エクスポートの外を指していたリンクは**そのまま残し、件数を報告します**。
- **添付も一緒に入ります**。通常のアップロードと同じ経路を通るので、ストレージの上限が効きます。上限で入らなかったファイルは**理由つきで一覧に出ます**。
- **乗り換え元のツールにあって、Wikistead に同じ機能が無いものは、名前で報告します**。たとえば Obsidian の Canvas や Dataview のブロック、Wikistead が解釈できない Confluence のマクロです。これらはページになりません。レポートに「どのページの何が落ちたか」として 1 つずつ出ます。
- **読めない記法も名前で報告し、アーカイブ自体はそのまま取り込みます**。Confluence の古い保存形式（`ac:` で始まるタグ）が HTML エクスポートの中に残っていることがあります。これらは変換しませんが、レポートに 1 つずつ名前が出て、中の文章はページに残ります。他のページはそのまま入ります。
- **タイトル**は、アーカイブが自前の目録を持っていない限り、フォルダ名とファイル名から付けます。
  Docmost だけは逆向きの例外です。ファイル名にはタイトルの文字がすべて入るわけではなく（`/` は落ちます）、元のタイトルは各ファイルの先頭の見出しに残っています。そちらをタイトルとして読み、その見出しは本文には残しません。
- **Docmost のページアイコンは引き継ぎません**。ここのページはアイコンを持たないためです。アイコンが付いていたページはレポートに 1 つずつ出るので、ナビゲーションに使っていた場合は何を作り直すか分かります。

## 大きな取り込み

数百ページまでは、その場で終わります。それを超えると**ジョブ**になり、取り込み ID がすぐ返って、画面が進捗を追います。**レポートは接続より長生きします**。タブを閉じても失われず、同じ ID で後から見られます。

**1 つのスペースで同時に走る取り込みは 1 件**です。実行中に 2 件目をアップロードすると断られ、画面は**実行中の取り込みに切り替わります**。終わるのを待ってから、もう一度アップロードしてください。

## 権限

取り込みには**対象スペースの編集権限**が必要です。権限の規則は、人がページを書くときと同じです。**ゲストは取り込めません**。
