---
title: 他のツールから取り込む
---

他の wiki のエクスポートをアップロードすると、その中身がスペースのページとして再現されます。形式は**アーカイブ自体から判別**するので、古いツールが出したファイルをそのまま渡してください。

| 取り込み元 | アップロードするもの |
|---|---|
| **Obsidian** | vault フォルダを zip にしたもの |
| **Notion** | 公式の Markdown & CSV エクスポート |
| **Confluence** | HTML エクスポート |
| **Wikistead** | この製品が書き出した zip（ワークスペース間の移動に使います） |

## 取り込みの手順

スペースを開き、**スペース設定 → インポート**に進みます。アーカイブを選んで開始します。終わると同じ画面にレポートが出ます。

取り込んだページは**入った時点で公開されます**。先に自分で目を通してから見せたい場合は、開始する前に公開のスイッチをオフにしてください。すべて下書きとして入ります。

大きなアーカイブはリクエストの中では処理せず、サーバ側の仕事になります。そのときは画面のアドレスにその取り込み自身の id が付きます。**このページを離れても構いません**。進み具合もレポートもサーバが持っているので、あとから同じリンクを開けば続きが見られます。1 つのスペースで同時に走る取り込みは 1 件までです。

## 何が入り、何が入らないか

**ページは公開された状態で入ります。** 取り込みが終わった時点で読めます。公開スペースなら、ワークスペースの外からも読めるようになります。これは開始する前に画面が伝えます。

**公開のスイッチをオフにした場合**は、すべて下書きとして入ります。このスペースを編集できる人にしか見えず、閲覧面は「このページは空です」と言い、エクスポートも空で返ります。**この 3 つは同じことの言い換え**です。下書きには公開済みの版が無く、これらの面が見せているのはその版だからです。

最後に出るレポートは、**入らなかったものを件数ではなく名前で**挙げます。

- **取り込んだページどうしのリンクは書き換えられます**。エクスポートの外を指していたリンクは**そのまま残して数えます**（推測で書き換えません）。
- **添付も一緒に入ります**。通常のアップロードと同じ経路を通るので、ストレージの上限が効きます。上限で入らなかったファイルは**理由つきで一覧に出ます**（黙って落とすことはありません）。
- **乗り換え元のツールにあって、Wikistead に同じ機能が無いものは、名前で報告します**。たとえば Obsidian の Canvas や Dataview のブロック、Wikistead が解釈できない Confluence のマクロです。これらはページになりません。レポートに「どのページの何が落ちたか」として 1 つずつ出ます。
- **読めない記法も名前で報告し、アーカイブ自体はそのまま取り込みます**。Confluence の古い保存形式（`ac:` で始まるタグ）が HTML エクスポートの中に残っていることがあります。これらは変換しませんが、レポートに 1 つずつ名前が出て、中の文章はページに残ります。**その 1 ページのために、隣の何百ページごと断ることはしません。**
- **タイトル**は、アーカイブが自前の目録を持っていない限り、フォルダ名とファイル名から付けます。

## 大きな取り込み

数百ページまでは、その場で終わります。それを超えると**ジョブ**になり、取り込み ID がすぐ返って、画面が進捗を追います。**レポートは接続より長生きします**。タブを閉じても失われず、同じ ID で後から見られます。

**1 つのスペースで同時に走る取り込みは 1 件**です。実行中に 2 件目をアップロードすると、待ち行列に入るのではなく断られます（2 つのアーカイブが同じツリーに混ざらないようにするため）。そのとき画面は**実行中の取り込みに切り替わります**。いつ試し直せばよいか勘で待つのではなく、走っているほうが終わるのを見ていられます。

## 権限

取り込みには**対象スペースの編集権限**が必要です。ページは**エディタが使うのと同じ経路**で作られるので、人が書くときに適用される規則を、取り込みだけがすり抜けることはありません。**ゲストは取り込めません**。共有リンクから来た人には、この経路が閉じています。
