---
title: 取り込めないもの
---

**取り込みは完全ではありません。** ページの大部分はそのまま届きますが、こちらに同じ機能が無いものは
届きません。

## そもそも対応していないもの

- **Confluence は HTML の書き出しだけ。** XML のスペースバックアップは読みません。REST API も使いま
  せん。API を使うということは、Confluence の資格情報を預かって外へ通信するということで、アップロード
  されたファイルを読むのとは信頼の大きさが違います。手元にあるのが XML バックアップなら、スペースの
  書き出し画面から HTML で出し直してください。
- **Obsidian のブロック参照。** `[[Note#^id]]` は段落を指していますが、Wikistead には段落を指す仕組みが
  ありません。リンクはページに解決され、参照そのものは失われます。見出しへのリンクは事情が違います。
  指定は落ちますが、見出し自体はページの中にあります。
- **Notion のコールアウトとトグル。** Notion はこれを Markdown 書き出しの中に HTML として書きます。
  推測で別のものに変換せず、その HTML のまま届きます。
- **Confluence の添付ファイルへのリンク。** ファイル自体は取り込まれます。リンクは、アーカイブがその
  ファイルを持っていれば張り直し、持っていなければ報告します。

## 運べなかったものの名前

取り込みのレポートが、届かなかったものを**名前で**、それがどのページのものかと一緒に並べます。**自分の
アーカイブについての答えはそこにあります**。あらかじめ約束するのではなく、アップロードされたファイルを
実際に見た結果だからです。
