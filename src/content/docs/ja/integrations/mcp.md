Wikistead は **MCP**（Model Context Protocol）に対応しています。MCP に対応したアシスタント（Claude、エディタの拡張、自作のエージェントなど）から、ワークスペースの内容を読み取らせたり、下書きを書かせたりできます。ページの中身をチャット欄に貼り付ける必要はありません。このとき、アシスタントは**あなた本人の権限で**動きます。

## つなぐ

アシスタントに、ワークスペースの MCP エンドポイント `https://<ワークスペースのホスト>/api/mcp` を指定します。認証は OAuth です。アシスタントが自動で設定を取得してクライアント登録を行い、続いて、いつもどおりのサインイン画面と許可画面が表示されます。発行されるトークンは**あなたに結びついた**もので、ワークスペース全体のキーではありません。あなたが持っていない権限が、この経路で得られることはありません。

メンバーがアシスタントをつないでよいかどうかは、管理者がサインイン方法ごとに決めます。**管理 → 認証**では、サインイン方法ごとに「AI ツール接続（MCP）」のスイッチがあります。オフにすると、そのサインイン方法で入るメンバーは MCP を使えなくなります。サインインの方法そのものは変わりません。

## 使えるツール

| ツール | できること |
| --- | --- |
| `list_spaces`, `list_pages` | ワークスペースの中を見て回る |
| `get_page` | ページの公開済み Markdown を読む |
| `search` | 全文検索（検索ボックスと同じく、見える範囲だけ） |
| `get_backlinks` | このページへのリンク元を調べる |
| `get_syntax_reference` | マクロの記法を取得する（エディタと同じ定義から生成した正式な一覧） |
| `create_page` | ページを作る（下書きとして作られます） |
| `edit_body` | ページの**下書き**に段落を追加する、または見出しの下の節を差し替える |
| `publish_page` | 下書きを公開して版を記録する |
| `create_comment` | ページにコメントする |

読み取りのツールはどのプランでも使えます。**書き込みのツールは、上位プランで使える機能**です（`mcpWrite`。[プラン別の機能一覧](/ja/reference/plan-contents/)を参照してください）。書き込みが使えない場合でも、読み取りのツールと、すでに作成した接続はそのまま利用できます。

## アシスタントにできないこと

- **あなたの権限を超えることはできません。** ツールの呼び出しは、そのつどあなたの権限で確かめられます。あなたが編集できないページは、アシスタントにも編集できません。権限のない人に返すのと同じ応答が返るため、そのページが存在するかどうかも分かりません。
- **うっかり公開してしまうことがありません。** `edit_body` が書くのは下書きです。公開は別のツールなので、アシスタントが下書きを整えることと、読者に見える内容が変わることは、別の操作です。公開した時点で、誰が公開したかが分かる版として記録されます。
- **存在しない記法を書くことはありません。** `get_syntax_reference` はエディタと同じマクロの定義から生成されるので、アシスタントが書くコールアウトやテーブルは、Wikistead が実際に解釈できる記法になります。

## 下書きの扱い

`edit_body` は、いま編集中の下書きをその場で書き換えます。そのページを開いている人には、変更がすぐに表示されます。アシスタントは裏でファイルを書き換えるプロセスではなく、もう 1 つのカーソルとして振る舞います。そのため、次の 2 点が保証されます。

- 編集は**追記か、見出し 1 つ分の差し替え**に限られます。「ページ全体を書き直す」呼び出しはないので、頼んでいない部分がいつのまにか消えることはありません。
- 共同編集の接続が一時的に切れているときは、ツールがエラーを返すので、アシスタントは時間をおいて実行し直せます。代わりに公開済みの本文を上書きする、といった動作はしません。
