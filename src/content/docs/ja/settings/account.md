---
title: アカウント設定
---

個人設定は**設定 → アカウント**にあります——ここにあるものはすべてあなただけのもので、管理者は要りません。タブは 7 つ：

| タブ | 中身 |
|---|---|
| **プロフィール** | 表示名（IdP が送ってきた名前の上書き）とアバター。 |
| **エディタ** | 編集スタイル——[Vim モード](/ja/editor/vim/)のキーマップトグルもここ。 |
| **テーマ** | ライト / ダーク / システム。 |
| **通知** | [ウォッチ](/ja/guides/notifications/)の届き方。 |
| **API キー** | 自分の持つ個人 API キー——ワークスペースがメンバー発行を許していればここで発行、そうでなければ保有分の一覧。 |
| **セキュリティ** | 自分の第 2 要素：認証アプリ（TOTP）の登録・パスキーの登録・どちらの削除も。どの方式を受け付けるかは[テナントのポリシー](/ja/admin/sign-in-methods/)です。 |
| **データ** | **見えるものすべて**を 1 つの Markdown ZIP でエクスポート。 |

## 知っておくべき 2 点

- **エクスポートは意図的に個人のものです。** 自分に見える知識を持ち出すことは、全プランで全メンバーの権利です（Open formats）——だから管理コンソールでなくここにあります。view でフィルタされます：読めるものを持ち出せます。
- **設定はアカウント単位で、ワークスペースの強制ではありません。** キーマップ・テーマ・通知の好みは*あなた*に付いてきます。管理者はポリシー（どの扉・どの要素方式が存在するか）を決め、あなたはその中で好みを決めます。

## リファレンス

アカウント設定の完全な生成カタログ——すべてのキー・型・既定値、リリース済みコードから抽出——は[アカウント設定リファレンス](/ja/reference/generated/account-settings/)にあります。
