---
title: アカウント設定
---

個人の設定は**設定 → アカウント**にあります。ここでの設定はすべて自分だけに適用されるもので、管理者に依頼する必要はありません。タブは 7 つです。

| タブ | 中身 |
|---|---|
| **プロフィール** | 表示名（IdP から届いた名前を上書きできます）とアバター。 |
| **エディタ** | 編集スタイルの設定。[Vim モード](/ja/editor/vim/)のキーマップもここで切り替えます。 |
| **テーマ** | ライト / ダーク / システム。 |
| **通知** | [ウォッチ](/ja/guides/notifications/)の届き方。 |
| **API キー** | 自分が持っている個人 API キー。ワークスペースがメンバーによる発行を許可していれば、ここで発行できます。許可されていない場合は、すでに持っているキーの確認のみできます。 |
| **セキュリティ** | 自分の 2 要素認証。認証アプリ（TOTP）とパスキーの登録・削除は、ここで行います。**リカバリコード**もここです（下記）。どの方式を受け付けるかは[ワークスペースの設定](/ja/admin/sign-in-methods/)で決まります。 |
| **データ** | **自分に見えるものすべて**を 1 つの Markdown ZIP でエクスポート。 |

## リカバリコード

2 要素認証を設定した端末やキーが手元から失われても、**リカバリコードがあれば誰にも頼らずに自分のアカウントへ戻れます**。セキュリティタブの、要素一覧の下にあります。

- **使い切りのコードが 10 本、表示は 1 度きりです。** 出てきたその場で控えてください。あとから読み直す手段はありません。控える場所は、復旧のときに手元にある場所を選びます。復旧したい端末の中に保存すると意味がなくなります。
- **作成のときに、もう一度サインインの確認を求めます。** 認証アプリのコード・パスキー・パスワードのいずれかで確認します。サインイン済みというだけでは作成できません。そこを通してしまうと、セッションを盗んだ人が 2 要素認証を恒久的に迂回する手段を自分で作れることになります。
- **コードを使うのは「入る」ではなく「リセットする」操作です。** このアカウントの 2 要素認証はすべて解除され、残りのコードも無効になり、開いているセッションはすべて終了します。入り直したあとで認証アプリを登録し直し、コードも作り直してください。これは管理者が行う[要素の解除](/ja/admin/members/)と同じ操作を、自分で実行できるようにしたものです。
- **作成時と使用時に、本人へメールが届きます。** 身に覚えのないメールが届いたら、それが気づくきっかけになります。
- **作り直すと、いま持っているコードは使えなくなります。** 有効なセットは常に 1 つだけなので、置き換えたあとの紙は無効です。
- **2 要素認証を設定できるメンバーなら誰でも使えます。** 管理者に限りませんし、ワークスペースの人数にも左右されません。端末を失うことは役割とも同僚の人数とも関係がなく、同僚がいたところで端末は見つからないからです。
- **セルフホストでは既定で有効です。** 管理者による解除だけに限定したい場合は `SECOND_FACTOR_RECOVERY=off` を設定します。その場合、タブには理由が表示されます。押しても拒否されるボタンは出しません。

## 知っておくと役に立つこと

- **エクスポートは個人のためのものです。** どのプランでも、すべてのメンバーが自分の読めるページを書き出せます。データを持ち出せることは製品の前提なので、この機能は管理コンソールではなく個人設定にあります。書き出せるのは自分が読めるページだけです。
- **設定はアカウントごとに保存され、ワークスペース側で一律に決められることはありません。** キーマップやテーマ、通知の設定は、どの端末で開いても自分のアカウントに紐づきます。管理者が決めるのはポリシー（どのサインイン方法や認証方式を使えるようにするか）で、その範囲の中でどう設定するかは自分で選べます。
