管理コンソール（サイドバーの**管理**、`/admin`）では、ワークスペースそのものを運用します。メンバーやロールの管理、サインインのポリシー、API キーや Webhook の設定、ブランディング、課金がここにまとまっています。

## 誰に何が見えるか

コンソールに表示されるのは、その人の権限で開ける画面だけです。権限のない画面は、選べない状態で表示されるのではなく、最初から出てきません。ほとんどのタブはワークスペースの**管理者**だけが開けますが、次の 3 つは権限を個別に与えられて、与えられた人にはそのタブだけが見えます。

- **サインイン方法**：接続管理の権限を持つ人に見えます。
- **ロール**：ロール管理の権限を持つ人に見えます。
- **監査ログ**：監査閲覧の権限を持つ人に見えます。

どの画面が開くかを決めているのはブラウザ側ではありません。ブラウザはサーバに問い合わせて、返ってきた答えを描画するだけです。メニューに何が見えていても、実際に操作したときにサーバ側でもう一度権限を確認します。

## タブ

このセクションには、次の各タブのページがあります。

- メンバーと招待、スペース、カスタムドメイン
- 認証、SCIM プロビジョニング（EE）
- ブランディング、外部埋め込み、モデレーション
- ロール、API キー、Webhook
- 監査ログ（EE）、アナリティクス（EE）
- 課金、孤立した下書き

公開タブについては[公開](/ja/publishing/public-spaces/)を参照してください。
