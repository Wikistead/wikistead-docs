---
title: Webhook
---

**管理 → Webhook**（管理者）は、外部システムをワークスペースのイベントに購読させます：エンドポイント URL を登録し、イベントを選ぶと、Wikistead は物事が起きたそばから署名付き HTTP 呼び出しを配信します——Wikistead を他ツールと組み合わせる push 側の半分です。

## イベント

購読できる語彙はワークスペースの**ドメインイベント**です——ページ公開・メンバー参加、その他。完全な一覧はリリース済みコードから生成されます：[ドメインイベントリファレンス](/ja/reference/generated/domain-events/)。新機能はイベントを伴って出荷され、リファレンスはリリースとともに動きます。

## 決して emit されないもの

Webhook は可視性を尊重します：**下書きと非公開コンテンツはイベントを生みません**。Webhook は「何が起きたか」の射影であり、読者が受けるのと同じルールで形づくられます——ルールを迂回する側道ではありません。

## 運用

各フックは配信状態を表示します。無効化したフックは受信を止めますが、忘れられはしません。Webhook がプランのレバーである場合、作成は制限されますが作成済みフックは配信を続けます（[entitlement レバー](/ja/reference/generated/entitlement-levers/)参照）。
