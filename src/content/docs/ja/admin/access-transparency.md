運用者がワークスペースに触れた場合、その事実は記録として残り、管理者が確認できます。

:::tip[EE]
この機能は Cloud / Enterprise エディションで提供されます。このページでは何ができるかを説明します。内部のしくみについては扱いません。
:::

## アクセス透明性とは

マネージドサービスの運用では、障害対応や法的義務への対応、データの復旧のために、運用者が顧客のワークスペースへ緊急アクセスすることがあります。アクセス透明性があると、運用者を信用するしかない状態ではなく、**記録で確かめられる**状態になります。運用者のアクセスは、そのワークスペースの管理コンソールにある開示ログに記録され、いつ、どんな理由でアクセスがあったかが残ります。

## 改ざんの検知

[監査ログ](/ja/admin/audit-log/)と同じしくみで、開示の記録は 1 つ前の記録のハッシュを含む形でつながっていて、コンソールから検証できます。運用者が自分のアクセス記録だけを、気づかれないように消すことはできません。

## 場所と閲覧できる人

開示ログは**管理 → 監査ログ**タブに、そのワークスペースの監査ログと並んで表示されます。閲覧できるのは管理者と、監査閲覧の権限を持つ人です（この機能を含むプランを契約している場合）。
