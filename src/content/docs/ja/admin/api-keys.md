---
title: API キー
---

**管理 → API キー**では、ワークスペースの API キーを発行し、一覧で管理します。API キーは、スクリプトや外部サービスが REST API を使うときの資格情報です。

## 権限を絞って発行する

キーは、作った人の権限をそのまま持つわけではありません。発行するときに、そのキーでどの操作を行えるかを指定します。

- **リソースの種類 × 読み取り / 書き込み**：たとえば「ページの読み取り」と「添付の読み取り」だけを許可し、他は許可しない、という形にできます。
- **対象スペース**：キーが使えるスペースを絞れます（任意）。一覧には各キーの権限範囲が表示されるので、発行から時間がたった後でも、そのキーで何ができるのかを確認できます。

キーの文字列そのものが表示されるのは、作成したときの**1 回だけ**です。それ以降、コンソールに出るのは名前や作成日などの情報だけです。

## 制限と失効

認証済みの API リクエストには、キーごと・ワークスペースごとに回数の上限があります（上限の値はプランによります。[プラン別の機能一覧](/ja/reference/plan-contents/)を参照してください）。キーを失効させると、すぐに使えなくなります。

## メンバー個人のキー

メンバーも[アカウント設定](/ja/settings/account/)から個人用のキーを持てます。メンバー自身が発行できるようにするか、管理者が発行したものだけを配るかは、ワークスペースの設定で選べます。REST API の詳しい仕様は、ソースリポジトリの [`docs/api-reference.md`](https://github.com/wikistead/wikistead/blob/main/docs/api-reference.md) にあります。
