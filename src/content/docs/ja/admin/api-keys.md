---
title: API キー
---

**管理 → API キー**（管理者）は、ワークスペースの API キー——スクリプトや連携が REST API に対して使う資格情報——を発行し、棚卸しします。

## 作りからして狭い

キーは所有者の全権ではなく、**グラント**とともに鋳造されます：

- **リソース種別 × read/write** — 例：*pages: read* と *attachments: read* だけ、他は何もなし。
- **スペーススコープ** — 任意でキーを選んだスペースに限定。一覧は各キーの届く先を表示するので、鋳造からずっと後でも「このキーは何に触れるか」を棚卸しできます。

生のシークレットが表示されるのは作成時の**一度だけ**。以後、コンソールはメタデータのみを表示します。

## 制限と失効

認証済み API トラフィックはキーごと・ワークスペースごとにレート制限されます（値はプランのレバーです——[entitlement レバー](/ja/reference/generated/entitlement-levers/)参照）。キーの失効は即時です。

## メンバー自身のキー

メンバーも[アカウント設定](/ja/settings/account/)から個人キーを持てます——メンバーが自分で発行できるか、管理者が鋳造したものを持つだけかはワークスペースの選択です。REST API の正典はソースリポジトリの [`docs/api-reference.md`](https://github.com/wikistead/wikistead/blob/master/docs/api-reference.md) です。
