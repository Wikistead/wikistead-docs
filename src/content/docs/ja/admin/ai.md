**管理 → AI** は、ワークスペース自身の AI プロバイダを接続し、AI 機能を有効にする画面です。下記の 2 つの手順が両方とも完了するまで、プロバイダには何も送信されません。AI は既定ですべて無効です。

## 1. プロバイダを接続する

プロバイダ（Anthropic・OpenAI・Gemini のいずれか）・モデル・自分の API キーを設定します。これは **bring-your-own-key** 方式で、ワークスペースは自分のプロバイダ契約の料金を自分で直接支払います。入力できたら**保存**を押してください。

### セルフホスト：自前のエンドポイントを指す

運用者が `AI_ALLOW_CUSTOM_ENDPOINT` を設定しているセルフホスト配備では、**互換エンドポイント（セルフホスト）** も選べます。Ollama・vLLM・LiteLLM など OpenAI 互換 API であれば、private・loopback アドレスを含めて指定できます。選ぶと**ベース URL** 欄が現れ、モデル・キーと並んで必須になります。この選択肢は Cloud には一切表示されません。セルフホストでも運用者がフラグを未設定の場合は表示はされますが無効になっており、その理由はプロバイダの一覧のすぐ下に名指しで表示されます（保存に失敗させて気づかせる形にはなっていません）。

- **モデル**は必須で、既定値はありません。自分のプロバイダアカウントで使える正確なモデル名を選んでください。
- **キーは書き込み専用**です。一度保存すると、この画面を含めどこにも表示されません（伏せ字でも表示されません）。変更したい場合は新しいキーを貼り付けてください。次回の保存で欄を空のままにすると、**プロバイダとベース URL が変わらない限り**既存のキーがそのまま保たれます。プロバイダを切り替える、またはベース URL を変更する保存では、その同じ保存で新しいキーが必要です（保存済みのキーは新しい接続先には引き継がれません）。
- **設定を削除**すると保存済みのキーも削除されます。再接続するには、もう一度キーを貼り付ける必要があります。

## 2. このワークスペースで AI を有効にする

プロバイダを接続しただけでは、何も有効になりません。**このワークスペースで AI を有効にする** は、このワークスペースがそのプロバイダへコンテンツを送信することへの同意です。管理者が有効にするまで無効のままで、無効に戻すと以後の利用は即座に止まります。

## 「利用できません」と表示される理由

メンバー向けの AI 機能は次の 3 つを確認し、いずれか 1 つでも欠けていれば AI は使えません。

- **プランに AI が含まれていること。** 含まれないプランもあります。
- **プロバイダが接続されていること**（上記）。
- **このワークスペースで AI が有効になっていること**（上記）。

AI タブは、どの条件が欠けているかを名指しで表示するので、なぜ機能がグレーアウトしているのか推測する必要はありません。

## セルフホスト

セルフホストの配備では、各ワークスペース自身の接続が使えるようになる前に、配備側でも AI プロバイダを組み込んでおく必要があります。詳しくは[セルフホストガイド](/ja/getting-started/self-hosting/)を参照してください。セルフホストの配備自体には課金も計測も一切発生しません。費用は、ワークスペースと接続先のプロバイダとの間のものです。
