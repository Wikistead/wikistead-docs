管理やセキュリティに関わる操作を、改ざんを検知できる形で記録した台帳です。誰がいつ、どの対象にどんな操作をしたかが残ります。

:::tip[EE]
この機能は Cloud / Enterprise エディションで提供されます。このページでは何ができるかを説明します。内部のしくみについては扱いません。
:::

## 何が記録されるか

ワークスペース全体を対象に、セキュリティに関わる操作が記録されます。メンバーとロールの変更、サインインポリシーの変更（変更前と変更後の値も残ります）、共有リンクの発行や失効、アクセスの記録、管理設定の変更などです。それぞれの記録には、操作した人、操作の内容、対象、時刻が入ります。

## 改ざんの検知

記録はハッシュでつながっています。1 つ 1 つの記録が、暗号技術によってそれ以前のすべての記録と結び付いていて、コンソールから最初から最後まで検証できます。記録を書き換えたり削除したりすると検証が通らなくなるので、このログを見れば、何が起きたかに加えて、その記録が後から書き換えられていないことも確かめられます。

## 場所と閲覧できる人

**管理 → 監査ログ**にあります。管理者と、監査閲覧の権限を持つ人が開けます。監査を担当する人に、他の管理権限を与えずに台帳だけを見てもらえます。
