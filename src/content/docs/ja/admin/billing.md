Cloud をお使いの場合、**管理 → 課金**で契約の状態を確認できます。現在の**プラン**、上限と現在の**人数**、使用中の**ストレージ**が表示されます。無料プランのワークスペースには**Pro にアップグレード**、課金設定済みの Cloud ワークスペースには**課金を管理**が表示され、後者は課金ポータルを開きます。

このタブについて、知っておきたいことが 3 つあります。

- **ゲストには課金しません。** 人数として数えるのはメンバーだけです。[共有リンク](/ja/guides/share-links/)から来た人が何人で一緒に書いても、費用は増えません。
- **プランを下げてもデータは消えません。** 下げたプランの上限を超えている場合、できなくなるのは、新しい招待やアップロードなど**これから増やす操作**だけです。メンバーが削除されることも、書いたものが消えることもありません。機能ごとの詳しい扱いは[プラン別の機能一覧](/ja/reference/plan-contents/)にあります。
- **セルフホストの Community Edition には課金がありません。** すべての機能が無制限で使えます。このタブは Cloud のためのものです。

## セルフホストの Community Edition では「使用量」タブになる

セルフホストのビルドは課金まわりのコード自体を持たないため、同じ画面が**管理 → 使用状況**として表示されます。プランも課金もアップグレードの案内もなく、**今期の使用量**という見出しの下に、この配備がこれまでに使った分（現在は AI トークン）が並ぶだけです。上限も課金も無いままですが、自分の実費を把握したいセルフホスターには意味のある数字です。
