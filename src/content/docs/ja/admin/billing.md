Cloud をお使いの場合、**管理 → 課金**で契約の状態を確認できます。現在の**プラン**、上限と現在の**人数**、使用中の**ストレージ**が表示されます。無料プランのワークスペースには**Pro にアップグレード**、課金設定済みの Cloud ワークスペースには**課金を管理**が表示され、後者は課金ポータルを開きます。

このタブについて、知っておきたいことが 3 つあります。

- **ゲストには課金しません。** 人数として数えるのはメンバーだけです。[共有リンク](/ja/guides/share-links/)から来た人が何人で一緒に書いても、費用は増えません。
- **プランを下げてもデータは消えません。** 下げたプランの上限を超えている場合、できなくなるのは、新しい招待やアップロードなど**これから増やす操作**だけです。メンバーが削除されることも、書いたものが消えることもありません。機能ごとの詳しい扱いは[プラン別の機能一覧](/ja/reference/plan-contents/)にあります。
- **セルフホストの Community Edition には課金がありません。** CE の上限はすべて無制限です（ただし一部の Cloud 限定機能は、上限の有無に関わらずそもそも CE のビルドに実装がありません）。このタブは Cloud のためのものです。

## ストレージ

ストレージは**添付ファイル**と**ページの履歴**（ページごとに保存されている公開版すべて）を合わせた、その時点での合計量です。AI 利用量のような月次カウンターとは違い期間でリセットされる数字ではないため、月次の使用量とは別に、独立した行として表示されます。

今表示されている数字は計測のみで、まだ何かを止める働きはしていません。合計がどれだけ増えても、添付のアップロードもページの公開もそのまま行えます。将来この上限が有効になった場合でも、止まるのは**新規のページ作成と新規の公開だけ**で、既存ページの編集やすでに公開済みの内容が影響を受けることはありません。上限の 9 割に近づくと、その旨の通知が表示されます。

## セルフホストの Community Edition では「使用量」タブになる

セルフホストでは、同じ画面が**管理 → 使用状況**として表示されます。プランも課金もアップグレードの案内もなく、**今期の使用量**という見出しの下に、この配備が使った分（現在は AI の利用量）が並びます。上限も課金もありませんが、自分の実費を把握するのに使えます。
