IdP から SCIM を使って、メンバーの追加と停止を自動化できます。

:::tip[EE]
この機能は Cloud / Enterprise エディションで提供されます。このページでは何ができるかを説明します。内部のしくみについては扱いません。
:::

## 何ができるか

**管理 → SCIM** では、この機能を含むプランのワークスペースで **SCIM トークン**を発行し、IdP のプロビジョニング先として Wikistead の SCIM 2.0 エンドポイントを設定できます。以降、メンバー一覧は IdP 側の操作で更新されます。

- IdP でアプリに追加された人は、招待なしで**メンバーになります**。
- IdP から外された人は、Wikistead 側で**停止されます**。退職の処理を人事側で済ませられるので、Wikistead 側で同じ作業を繰り返す必要がありません。
- 属性の変更も同じ経路で反映されます。

## 注意点

- SCIM による停止は、[メンバー画面](/ja/admin/members/)からの停止と同じで、元に戻せますしデータも消えません。書いたページも履歴も残ります。
- 停止されたメンバーの**2 要素認証は自動では削除されません。** 削除するには、管理者が明示的に操作する必要があります。再入社した人のアカウントが、以前より保護の弱い状態で復活することはありません。
- ゲストは SCIM の対象外です。もともと IdP に登録されている人ではないからです。

[SAML SSO](/ja/admin/saml-sso/) と組み合わせると、サインインからアカウントの作成・停止までを IdP 側でまとめて扱えます。
