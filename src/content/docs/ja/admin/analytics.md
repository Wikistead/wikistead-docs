ワークスペース全体でも、スペースごとでも、ページがどれだけ読まれているかを確認できます。どのページが実際に役立っているかが分かります。

:::tip[EE]
この機能は Cloud / Enterprise エディションで提供されます。このページでは何ができるかを説明します。内部のしくみについては扱いません。
:::

## 何が見えるか

ページごと、スペースごとの閲覧数と、その日ごとの推移が見えます。チームがよく参照しているページと、読まれなくなったページが分かります。**メンバー**については、ページのダッシュボードで誰が読んだかも確認できます。**ゲストと匿名の読者は、合計の人数にだけ反映されます。** 共有リンクから読んだ人の名前が一覧に出ることはありません。

## 場所と閲覧できる人

ワークスペース全体の数字は**管理 → アナリティクス**で管理者が、スペースごとの数字は各スペースの**アナリティクス**タブでそのスペースのマネージャが確認できます。閲覧数を記録するのは、この機能を含むプランのワークスペースだけです。含まれないワークスペースでは、記録しておいてダッシュボードだけ隠すのではなく、閲覧履歴そのものを残しません。
