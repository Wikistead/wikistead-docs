**管理 → ブランディング**では、ワークスペースの見た目を決めます。設定できるのは、ヘッダーとサインイン画面に出る**ロゴ**と、**アクセントカラー**です。スペースごとに別のアクセントカラーを指定して上書きすることもできます（各スペースの設定で行います）。設定するには**ロゴをアップロード**、外すには**削除**を押します。

間違えやすい点が 2 つあります。

- **個人のテーマ設定とは別のものです。** メンバーが選んだライト / ダーク / システムの設定（[アカウント設定](/ja/settings/account/)）は、ブランディングの影響を受けません。ブランディングが決めるのはワークスペースの見た目であって、各メンバーのテーマ設定ではありません。
- **カスタムブランディングがプランに含まれない場合**（[プラン別の機能一覧](/ja/reference/plan-contents/)を参照）、そのワークスペースは既定の見た目になります。設定した内容は保存されたままなので、プランを上げれば再び反映されます。
