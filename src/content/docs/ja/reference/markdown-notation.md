エディタが描画する記法の早見表です。1 記法 1 行 + 例だけ。マクロ（`:::` ディレクティブやコードフェンスで書く図など）は[マクロ記法](/ja/reference/macro-notation/)を参照してください。

## CommonMark と GFM

| 記法 | 例 |
| --- | --- |
| 見出し | `# H1` 〜 `###### H6` |
| 太字 | `**太字**` |
| 斜体 | `*斜体*` |
| 取り消し線 | `~~取り消し線~~` |
| インラインコード | `` `code` `` |
| リンク | `[文字列](/p/<pageId>)`（内部）または `[文字列](https://example.com)` |
| 引用 | `> 引用文` |
| 箇条書き | `- 項目` |
| 番号付きリスト | `1. 項目` |
| タスクリスト | `- [ ] 未完了` / `- [x] 完了` |
| テーブル | `\| a \| b \|`（標準の GFM パイプテーブル） |
| 水平線 | `---` |

## タグ（フロントマター）

ページのタグは、文書の先頭に置く YAML フロントマターに書きます。

```md
---
tags: [recipes, dinner]
---
```

タグは単なる文字列です（大文字小文字を区別しません）。インラインの `#tag` 記法はありません。

## ハイライト

```md
==ハイライト==
```

`<mark>` として描画されます。前後に空白がある `=`（`a == b`）はそのまま文字として残ります。コード例の比較演算子が誤反応しないようにするためです。

## 脚注

```md
出典が要る記述。[^1]

[^1]: 注釈の本文。ここは 1 行で書きます。
```

参照 `[^1]` は本文のどこに書いても構いません。定義行はどこに書いても集められ、番号が振られます。

## 数式

インライン数式は `$` 1 つで囲みます。

```md
面積は $\pi r^2$ です。
```

ブロック数式は `$$` を単独の行で挟みます。

```md
$$
E = mc^2
$$
```

どちらも KaTeX で描画されます。インラインコード `` `code` `` やコードフェンスの中の `$` は数式として読まれません。

## コードフェンスの属性

フェンスの言語指定のあとに書く情報文字列は、一般的な書き方に合わせています。知らない属性を書いても取り除かれず、そのまま残ります。

````md
```ts title="app.ts" showLineNumbers {1,3-5}
const x = 1
```
````

- `title="…"` はフェンスにラベルを付けます。
- `showLineNumbers` は行番号を表示します。
- `{1,3-5}` は 1 行目・3〜5 行目をハイライトします（カンマ区切りの単独行または範囲）。
