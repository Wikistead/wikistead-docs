---
title: マクロ記法
---

組み込みマクロの書き方を 1 ページにまとめました。ここにあるものはすべて標準の Markdown の形をしています。データを持つブロックは**言語タグを付けたコードフェンス**、中身が Markdown のブロックは **`:::` ディレクティブ**です。独自の記法はありません。

各マクロの詳しい解説は、[コールアウト](/ja/editor/callouts/)、[テーブル](/ja/editor/tables/)、[図](/ja/editor/diagrams/)、[ドローイング](/ja/editor/drawings/)、[レイアウト](/ja/editor/layout-macros/)、[埋め込み](/ja/editor/embeds/)、[タグ](/ja/editor/tags/)、[ページリスト](/ja/editor/page-lists/)、[タスク](/ja/editor/tasks/)の各ページにあります。

## コールアウト

```md
:::note
本文の Markdown。
:::
```

種類は `note`・`info`・`tip`・`warning`・`danger` の 5 つです。ラベルは省略できます（例：`:::warning[移行の前に]`）。

## 折りたたみとレイアウト

- 折りたたみ：`:::details[要約]` の中に本文を書きます。
- カラム：`:::columns` の中に `:::column` を並べます。
- タブ：`:::tabs` の中に `:::tab[ラベル]` を並べます。

## 進捗リング付きタスクリスト

```md
:::todo[やること]
- [ ] タスク
- [x] 完了
:::
```

`:::todo` で囲まなくても、素の GFM の `- [ ]` タスクリストはそのまま動きます。

## 図（コードフェンス）

- Mermaid：` ```mermaid ` のフェンスに図のテキストを書きます。
- PlantUML：` ```plantuml ` のフェンスに `@startuml` から `@enduml` までを書きます（描画サービスを設定していない環境では、ソースがそのまま表示されます）。
- Excalidraw：` ```excalidraw `（エディタ上で描きます。本文はシーンの JSON です）。

## 自動で作られる一覧（読み取り専用）

- タグを持つページ：`:::tagged` の本文にタグ名を書きます。
- このページの子ページ：`:::children`（本文は空にします）。

## 埋め込みとページ埋め込み

- 別ページの内容を埋め込む：`:::embed-page` の本文にページ id を書きます。
- 許可リストに載っている外部 URL を埋め込む：`:::embed-external` の本文に URL を書きます。

## テーブル（セル結合・配置あり）

標準の GFM パイプテーブルはどこでも使えます。セルの結合や配置が必要なときは `:::table` を使い、その中に HTML の `<table>` を書きます。

## コードフェンス

フェンスの言語指定は、一般的な書き方に合わせています。知らない属性を書いても取り除かれず、書いたまま残ります。

````md
```ts title="app.ts" showLineNumbers {1,3-5}
const x = 1
```
````
