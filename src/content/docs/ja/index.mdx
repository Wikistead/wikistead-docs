<CardGrid stagger>
  <Card title="エディタ" icon="pencil">
    画面は 1 つだけ。コールアウトやテーブル、図、タスクがその場で描画され、ページの中身は素の Markdown のままです。Vim も使えます。
    [エディタガイド →](/ja/editor/callouts/)
  </Card>
  <Card title="共同編集" icon="comment-alt">
    招待の手続きは要りません。リンクを渡せば、ゲストはその権限の範囲でリアルタイムに書けて、失効は 1 回の操作で済みます。
    [共有リンク →](/ja/guides/share-links/)
  </Card>
  <Card title="整理する" icon="open-book">
    スペース、ページが増えても迷わないツリー、テンプレート、版の履歴。本文にページの名前を書けば、それがリンクになります。
    [ページとスペース →](/ja/guides/pages/)
  </Card>
  <Card title="公開する" icon="rocket">
    非公開のまま使うことも、チームだけに、Web 全体に、静的サイトとして公開することもできます。独自ドメインにも対応します。
    [公開 →](/ja/publishing/public-spaces/)
  </Card>
  <Card title="管理する" icon="setting">
    メンバー、ロール、サインイン方法、2 要素認証、API キー、Webhook。どの画面も、権限を持つ人にだけ表示されます。
    [管理 →](/ja/admin/)
  </Card>
  <Card title="リファレンス" icon="information">
    プランに含まれるもの、Webhook のイベント、アカウント設定の一覧です。
    [リファレンス →](/ja/reference/)
  </Card>
</CardGrid>
