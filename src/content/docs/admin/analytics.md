Page-view analytics for the workspace and its spaces — which knowledge is actually being read.

:::tip[EE]
This capability ships in the Cloud/Enterprise edition. This page describes what it does; how it is built is not part of the docs.
:::

## What it shows

View counts and daily series per page and per space, so you can see which pages carry the team and which have gone quiet. For **members**, a page's dashboard can answer *who* has viewed it; **guests and anonymous readers are only ever counted in aggregate** — a share link's audience is never turned into a roster.

## Where and who

Workspace-wide: **Admin → Analytics** (admins). Per space: the space's **Analytics** tab, for that space's managers. Collection runs only where the workspace is entitled — an unentitled workspace collects no view history at all, rather than collecting it silently and hiding the dashboard.
