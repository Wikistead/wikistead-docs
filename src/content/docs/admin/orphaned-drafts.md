---
title: Orphaned drafts
---

Drafts are visible to their creator only — so when a member leaves, their unpublished drafts would otherwise be invisible to everyone forever. **Admin → Orphaned drafts** (admins) is the recovery surface for exactly that case: it lists drafts whose creator is no longer active in the workspace, so an admin can rescue the work instead of losing it.

This tab is deliberately narrow. It does not open a window into *active* members' drafts — creator-only visibility holds while the creator is here. It exists for the departed-author case only: knowledge someone started should survive the person leaving.
